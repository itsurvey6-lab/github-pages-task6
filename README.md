
# GitHub Pages - Static Website Hosting

## Project Overview
This project demonstrates how to create and deploy a responsive
static website using GitHub Pages.

## Technologies Used
- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## Features
- Responsive layout
- Navigation links
- Feature cards
- Custom CSS styling
- Free static website hosting

## Deployment Steps
1. Created the website using HTML and CSS.
2. Initialized a Git repository.
3. Pushed the project to GitHub.
4. Enabled GitHub Pages from the main branch.
5. Selected the root folder as the deployment source.
6. Verified the published website.

GitHub Pages Interview Questions and Answers


1. What is GitHub Pages?

Answer: GitHub Pages is a free static website hosting service provided by GitHub. It allows us to publish HTML, CSS, JavaScript, and other static files directly from a GitHub repository.
Example from my project: I created an index.html file, pushed it to GitHub, and enabled GitHub Pages to make my website publicly accessible.

2. Can you host dynamic applications on GitHub Pages?

Answer: GitHub Pages cannot run server-side applications or backend code such as Node.js, Express, PHP, or Python. However, it can host frontends that use JavaScript and static builds of frameworks such as React. The backend must be hosted separately.
Example: I can host a React frontend on GitHub Pages, but my Node.js API would need a separate hosting service.

3. What are the limits of GitHub Pages?

Answer: GitHub Pages is designed for static websites, not full backend applications. Its documented limits include:
- Recommended maximum source repository size: 1 GB.
- Published site size: 1 GB.
- Soft bandwidth limit: 100 GB per month.
- Build usage limit: 10 builds per hour for standard publishing, with exceptions for certain workflows.
These are service limits, not guaranteed performance levels. GitHub may apply additional usage policies.

4. How do you update a website hosted on GitHub Pages?

Answer: I update the website files locally, commit the changes, and push them to the GitHub repository. GitHub Pages automatically rebuilds and deploys the updated website when the configured publishing source changes.
